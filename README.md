# Deep-Learning-01

Welcome to the **Deep-Learning-01** repository! This project serves as a comprehensive learning resource and practical guide for mastering the fundamentals of Deep Learning. It includes detailed lecture notes, structured PDF guides covering core concepts, and hands-on Jupyter Notebooks mapping out foundational implementations.

## 📁 Repository Structure & Contents

The repository is organized as follows:

### 📚 Concept Notes & Guides (PDFs)
*   **1-4 Deep learnng.pdf** & **5-8 Deep LEarning.pdf** – Comprehensive introductory guides covering foundational Deep Learning concepts, architectures, and history.
*   **8-15 Activation functions.pdf** – In-depth study of neural network activation functions (e.g., ReLU, Sigmoid, Tanh, Softmax) and their mathematical properties.
*   **16-19 Loss Functions.pdf** – Detailed breakdown of different loss functions used for regression and classification tasks.
*   **20-24 Optimizers.pdf** & **20-26 Optimizers.pdf** – Exploration of optimization techniques and algorithms (e.g., SGD, Adam, RMSprop) to accelerate network training.
*   **Deeplearning.pdf** – Consolidated core summary reference guide for deep learning frameworks.

### 💻 Practical Implementations (Notebooks & Data)
*   **Basic.ipynb** – Introductory Jupyter Notebook walking through basic setups, operations, and foundational code constructs.
*   **Iris.csv** – The classic Iris flower dataset used for testing and deploying early-stage classification algorithms.
*   **Iris_prediction.ipynb** – A complete end-to-end practical project implementing a deep learning workflow to predict classes on the Iris dataset.

## 🚀 Getting Started

To explore or run the code locally, follow these quick steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   cd Deep-Learning-01
   ```

2. **Set Up an Environment:**
   It is recommended to use a virtual environment (like `venv` or `conda`) running **Python 3.8+**.

3. **Install Core Dependencies:**
   Ensure you have the required deep learning and data science libraries installed:
   ```bash
   pip install numpy pandas matplotlib scikit-learn notebook tensorflow torch
   ```

4. **Launch the Notebooks:**
   ```bash
   jupyter notebook
   ```
   Open `Iris_prediction.ipynb` or `Basic.ipynb` to begin interacting with the code.
